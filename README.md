# PIXEL BREAK

Pixel-art brick breaker for the web. Play with mouse, keyboard, or touch.

- 24 geometric levels with rising difficulty
- Special bricks: bomb, lightning, fire, ice, steel, gold
- 12 power-ups (expand, multi-ball, laser, shield, …)
- Local + server save for score and unlocked levels

## Play

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080).

| Control | Action |
| --- | --- |
| Mouse / touch | Move paddle, tap to serve |
| A / D or arrows | Move paddle |
| Space | Serve |
| P / Esc | Pause |

## Stack

Vite + TanStack Start + React + Canvas 2D.
